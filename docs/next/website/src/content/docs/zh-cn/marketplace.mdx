Herdr 插件市场是一个可供发现的社区插件索引。
访问 [herdr.dev/plugins](/plugins/) 浏览。它是公开 GitHub 仓库的自动索引,
而不是经过审核的目录。

## Vqro Extensions

Vqro 还提供由宿主管理的原生 Extensions 市场。从主菜单打开 **Extensions**,即可搜索
随程序提交的精选索引并按类别筛选。安装、移除、更新、回滚和永久删除数据分别需要确认。
对于固定版本的条目,Vqro 会获取精确的 Git 提交,验证源码归档、清单摘要和身份后再保存到
托管存储。对于从源码部署的代理集成,更新会保留上一个已验证产物用于回滚,回滚不会重新获取可变引用。Collections、Spaces、Delegation 和 Agent Status 当前是宿主内置的兼容提供程序:仓库固定版本用于证明对应源码,但实现仍编译在 Vqro 中,只能随 Vqro 二进制更新或回滚。它们使用公开的进程服务协议形状,但还不是独立构建的组件扩展。市场不会提供仅更改元数据的更新。移除扩展会保留配置和状态;只有单独执行 **delete data** 才会清除这些数据。内置条目显示在同一个 Extensions 界面中并可移除,但其兼容记录不是 package-v1 运行时记录。

只有当下载的可执行软件包中的所有服务都使用 `vqro:extension/service@1.0.0` 组件 world 时,宿主才会接纳它。这些服务作为 WebAssembly Component Model 组件在 Wasmtime 中运行,仅链接 Vqro WIT world,并受明确的宿主能力和资源限制约束。精选状态不会增加能力或权限。安装可以验证、实例化、协商、监督服务并在重启后恢复服务,但目前不会授予生产环境的宿主状态或终端租约、document-v2 提供程序注册、客户端可见发布或功能权威。旧版显式配置的进程插件属于独立兼容功能,不能作为 Extension 软件包安装。只有 Collections 提供按仓库的启用覆盖;没有实际运行时支持的操作不会显示。代理软件包状态与适配器部署状态会分别显示。

### 从精确 Git 修订安装

在 **Extensions** 中按 **g**,输入不含凭据的 HTTPS Git URL、完整的 40 字符提交,以及可选的仓库相对 `.vqrox` 路径。Vqro 只获取该提交,拒绝子模块和链接的软件包路径,并验证确定性软件包。如果任何服务请求原生进程运行时,整个软件包都会被拒绝。

确认页面显示 URL、提交、软件包与清单摘要、命名空间、组件服务和请求的能力。批准与这些摘要绑定。更新和回滚同样需要确认精确产物;这些操作不会替换或重启窗格 PTY。

## 浏览插件

[插件市场](/plugins/)会列出带有 GitHub 主题标签 `herdr-plugin`,并且默认分支中
至少包含一个必需元数据可解析的 `herdr-plugin.toml` 的公开仓库。你可以搜索仓库和
插件元数据,并按热度、最近活跃度或最新排序仓库卡片。每张卡片链接到源码仓库,
并列出其中发现的所有插件。

收录是自动且未经审核的。被列出只说明仓库给自己打了标签,并不代表 Herdr
审查过它,所以在安装任何插件之前,请先阅读[信任指南](/zh-cn/docs/plugins/#信任与安全)。

## 安装插件

插件市场是在安装之上增加的发现渠道,它不会取代安装。任何插件都可以直接从
GitHub 安装:

```bash
herdr plugin install owner/repo[/subdir...]
```

发布一个普通的公开 GitHub 仓库,在根目录或子目录放一个 `herdr-plugin.toml`
清单,这条命令就能用了。清单和编写参考见[插件](/zh-cn/docs/plugins/)。

## 让你的插件被收录

给公开仓库添加 GitHub 主题标签 `herdr-plugin`,并在默认分支中放置一个或多个
必需元数据可解析的 `herdr-plugin.toml`。清单可以位于根目录或子目录。插件市场
每个仓库显示一张卡片,并把每份有效清单列为可单独安装的插件。索引每 30 分钟
自动刷新。

## 条目会展示什么

每张卡片展示 GitHub 仓库的名称、作者、描述、star 数、主要语言和最后 push 时间。
插件行展示每份清单的 `name` 和 `version`,并链接到精确的源码目录。索引还会记录
清单路径、`id`、`name`、`version`、`platforms`、`min_herdr_version`,以及默认分支的
精确提交。Fork、已归档仓库、没有有效插件清单的仓库以及无效清单元数据都会被排除。
